# 成片字幕校时

剪辑师在成片上发现某句字幕时间不对时，选中该句所在的成片行，直接改它在成片里的起止时间；
系统把它换算回原片字幕，并把**同一条原字幕在所有选段（包括重复选段）里的成片行一起重算**。

换过选段后，剪辑师在成片字幕页接着核看：每行点「已核看」登记该行在原片中露出的毫秒区间，
系统按原字幕合并所有登记、逐行算出**尚未核看的成片时间区间**；登记可查看、可逐笔撤销。

FastAPI + SQLite，页面为服务端渲染，无前端构建。

## 启动

```bash
docker compose up --build
# 打开 http://localhost:8000
```

本地开发（Python 3.11+）：

```bash
pip install -r requirements-dev.txt
uvicorn app.main:app --reload
```

## 使用流程

1. **上传 CSV**（`/upload`，也可点“载入内置样例”）：
   - 原片字幕 CSV：`material_id,subtitle_no,start_ms,end_ms,text`（亦接受中文表头 `素材号,字幕号,开始毫秒,结束毫秒,正文`）
   - 选段 CSV：`material_id,start_ms,end_ms`，按成片顺序逐行列出，**允许同一素材重复出现**。
     各段在成片中首尾相接；所有区间**含起点、不含终点**。
   - 上传为整体替换并重算全部成片行；CSV 解析失败则原数据不变。
2. **成片字幕行**（`/rows`）：读取已保存的成片行，每行同时显示成片时间与原片时间、裁切标记，
   以及**尚未核看的成片时间区间**（缺口）；行与缺口在同一只读事务里取出，保证来自同一已提交状态。
3. **核看登记**（点某行的“已核看”）：
   - 只登记该行在原片中露出的毫秒区间（含起点、不含终点），由服务端按当前库内状态现算；
   - 同一原字幕的多笔登记合并成并集，计算它在各选段里的覆盖，逐行显示缺口；
   - 点“登记明细”可查看该原字幕的全部登记并**逐笔撤销**；撤销后仍被其他登记覆盖的部分保持已核看；
   - **重传选段后登记按原片区间沿用**（登记挂在原字幕上，与选段无关）；
   - **校时成功后仅该原字幕的登记失效**；重传原片字幕 CSV 或载入样例则清空全部登记；
   - 页面读出后若成片行或原字幕已变（行消失、行区间或字幕版本不符），登记被拒绝并提示刷新（HTTP 409），不产生任何写入。
4. **校时**（点某行的“校时”）：
   - 在本段成片范围内调整起止（毫秒），页面实时显示换算后的原片时刻；
   - **被切点裁掉的一端不能调整**（输入框禁用），服务端也会忽略该端入参、保留原片时刻；
   - 保存时只重算这条原字幕在各段中的成片行：补上新出现的行、撤下不再可见的行；
   - 若原字幕在该行读出后被改过（版本号校验），保存被拒绝并提示刷新（HTTP 409）；
   - 保存在校验/写库任一环节失败都会整体回滚，原字幕与成片行都保留上次结果。

## 自测

```bash
python -m pytest tests/ -q
```

`tests/test_flow.py` 用内置样例（素材 M1 被重复选为第 1、3 段）覆盖：

| 场景 | 验证点 |
| --- | --- |
| 样例载入 | 选段偏移 0/4000/6500，6 条成片行，裁切标记正确 |
| 重复选段校时 | 改第 1 段行终点 3000→2800，第 3 段同一句行同步为 [6500,7300) |
| 裁切端保护 | 起点被裁的行提交新起点被忽略，原片起点保持 1000 |
| 越界/起止颠倒 | 400，且原字幕与成片行都保持上次结果（事务回滚） |
| 行出现/消失 | 字幕缩到不与第 3 段相交则该行撤下，改回又补上 |
| 乐观并发 | 旧版本保存 → 409 并提示“刷新”，状态不变 |
| 上传 | 坏 CSV 不破坏原数据；新 CSV 整体替换并重算 |

`tests/test_review.py` 覆盖核看登记：

| 场景 | 验证点 |
| --- | --- |
| 登记与跨段覆盖 | 第 1 段行登记原片 [1000,3000)，第 3 段同一句行也无缺口；其它字幕不受影响 |
| 换段后的缺口 | 登记 [0,500) 后重传选段，登记沿用，新行缺口按原片区间重算为成片 [500,1000) |
| 撤销重叠登记 | 撤销 [1000,3000) 后该行缺口 [1000,2000)，[2000,3000) 仍被另一笔覆盖算已核看 |
| 重复登记 | 同区间两笔，撤销一笔仍全部已核看 |
| 校时失效 | 校时 M1#1 后仅它的登记清空，M1#2 的保留，缺口恢复整行 |
| 清空 | 重传原稿、载入样例后登记清空 |
| 过期拒绝 | 行区间变了/版本变了/行被重算移除 → 409 提示“刷新”，登记不写入、状态不变 |
| 页面 | 列表页缺口列、明细页查看与撤销、撤销不存在的登记有提示 |

## 已知限制（未完成）

- 时间输入只支持整数毫秒，未做 `HH:MM:SS,mmm` / 时间码解析与帧率换算。
- 上传是整体替换，没有增量合并；重新上传后旧的成片行 id 不保留。
- 单行校时，无批量调整、撤销/历史记录。
- 核看登记只按“行可见区间”整段登记，不能登记行内任意子区间；登记无备注/操作人；
  字幕当前不在任何选段里时，它的登记仍保留但列表页没有入口，只能按 URL 查明细。
- 无用户体系与权限；并发靠 SQLite 写事务 + 版本号乐观锁，冲突只能提示刷新后重试。
- 未做字幕正文编辑（只校时）；正文改动需重新上传原片字幕 CSV。
- 前端为简单服务端渲染，无波形/视频联动预览。
